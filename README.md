# Zoodomo

SaaS de fiches animaux pour refuges et vendeurs professionnels. Le refuge/vendeur gère ses fiches animaux (photos, description, statut) dans un espace membre, puis obtient un lien direct par espèce à placer sur son propre site — sans avoir à coder quoi que ce soit.

Projet en cours de développement, actuellement en local avec des données mockées (pas de Supabase branché pour l'instant). Voir `docs/` pour le brief complet, les décisions et l'avancement.
