# Zoodomo

SaaS de fiches animaux pour refuges et vendeurs professionnels. Le refuge/vendeur gère ses fiches animaux (photos, description, statut) dans un espace membre, puis obtient un lien direct par espèce à placer sur son propre site, sans avoir à coder quoi que ce soit.

Authentification, base de données et stockage des photos sur Supabase (RLS activé sur toutes les tables), emails transactionnels via Resend, interface disponible en français, néerlandais et anglais. Voir `docs/` (non suivi par Git) pour le brief complet, les décisions techniques et l'avancement.
